Phase 7G Legacy Browser Data Export

This page reads Condotel-related localStorage from the same browser origin as your Vite app and exports it to JSON for review before SQLite import.

Payments, transactions, NFC, settings, and similar keys are exported for review only. Phase 7G does not import them as verified backend records.

Open this page from http://localhost:5173/tools/legacy-localstorage-export.html. Do not open the HTML file directly from your file system because localStorage is origin-specific.
